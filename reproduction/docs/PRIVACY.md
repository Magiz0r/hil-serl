## 文档占位约定

| 示例 | 含义 |
| --- | --- |
| `~/hil-serl` | 当前用户的仓库位置 |
| `LOCAL_USER`、`robot_operator`、`/home/robot`、`/home/operator` | 示例账号或路径，不是实际账号 |
| `robot-nuc` | 示例 SSH 别名，应替换为本机 SSH 配置 |
| `${ROBOT_IP}`、`${NUC_IP}`、`${DESKTOP_IP}`、`${TAILSCALE_IP}` | 本机配置的设备地址；网页地址以启动输出为准 |
| `${NUC_RUNTIME}` | 实际 NUC 专用运行目录 |
| `${GRIPPER_DEVICE}`、`${CAMERA_DEVICE}` | 已核对的设备路径 |
| `$WANDB_ENTITY` | 用户自己的 W&B 工作区 |
| `<HOST_FINGERPRINT>`、`<RS485_SERIAL>`、`<CONTAINER_ID>` | 已隐藏的机器标识，不是可执行参数 |

命令示例默认在仓库根目录、激活 `hilserl` 环境后运行。含占位变量的部署和历史命令
需先按本机配置替换，不表示现在应执行这些操作。常用 Bash 启停入口保持原行为。
